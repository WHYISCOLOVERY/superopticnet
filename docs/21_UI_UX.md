# 21 UI UX

## Purpose

Define the visual and interaction standard for a modern ISP NOC + billing command center.

## Core Principles

- No table jungle.
- Summary first, details later.
- Context actions on every page.
- Visual status, badges and health scores.
- Less clutter, more filters/drawers.
- Use cards, charts, kanban, timelines, side panels, drawers, heatmaps and topology views.
- Avoid duplicate headers and nested page-in-page scroll areas.
- Menus must be compact, readable and not cover page content.

## Required Page Shapes

- Dashboard: visual control center.
- Customer list: searchable data explorer with online/offline visibility and quick actions.
- Customer360: tabbed profile with all customer context.
- Billing: finance dashboard plus payment tables and reconciliation.
- RADIUS: live session monitor and auth/reject analysis.
- OLT/ONT: topology, tree and signal health.
- NOC: live network map, alarms and root-cause panel.
- Tickets: kanban, SLA and detail timeline.
- Inventory: stock cards, barcode, handover and cable progress.
- HR/KPI: employee cards, schedules, attendance and performance.
- Security Center: anomaly cards and audit timeline.
- AI Copilot: compact assistant drawer that does not block the page.

## Empty/Error States

- Empty states must explain why no data appears and what action can populate it.
- Loading states use skeletons.
- Errors show cause, retry action and log reference where available.
