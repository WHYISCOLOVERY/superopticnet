# Daxili (on-premise) LLM provideri — kənar servis yoxdur

Date: 2026-07-25

## Qərar

Şirkət kənardan işləyən agent istəmir. AI tam **lokal** olmalıdır: model şirkətin
öz maşınında işləməli, məlumat heç vaxt kənara çıxmamalıdır. Ona görə DeepSeek
(və istənilən bulud provayderi) default deyil; agent daxili LLM runtime-ə
(Ollama, yaxud OpenAI-uyğun llama.cpp / LM Studio) qoşulur.

## Nə əlavə olundu

`ai-local-lib.php`:

- `app_ai_local_config()` — `AI_MODEL_PROVIDER=local`, `LOCAL_LLM_ENDPOINT`
  (default `http://127.0.0.1:11434`), `LOCAL_LLM_MODEL`, `LOCAL_LLM_API`
  (`ollama` | `openai`).
- `app_ai_local_is_loopback_url()` — **sərt loopback qapısı**: yalnız
  `127.0.0.0/8`, `::1`, `localhost`. Kənar host, `user:pass@…` və qeyri-http/s
  rədd olunur. Beləliklə agent fiziki olaraq internetə çıxa bilmir.
- `app_ai_local_http_transport()` — loopback-only HTTP transport; qeyri-loopback
  URL sorğudan əvvəl bloklanır (`non_loopback_blocked`).
- `app_ai_local_chat()` — Ollama-native (`/api/chat`) və ya OpenAI-uyğun
  (`/v1/chat/completions`) çağırış; hər iki cavab formatı parse olunur. Prompt
  yerli olsa da raw sirrlər (parol, API açar, Bearer) hər halda redaksiya olunur.
- `app_ai_local_status()` — runtime-in əlçatanlığını yoxlayır (model siyahısı).
- `app_ai_agent_chat()` — vahid giriş: əvvəl lokal model; lokal konfiqurasiya
  olunubsa, əlçatmaz olsa belə **səssizcə buluda keçmir**. Yalnız operator açıq
  şəkildə `deepseek` seçibsə xarici provayder işə düşür.

`copilot-agent.php` artıq `app_ai_deepseek_chat` yerinə `app_ai_agent_chat`
çağırır; LLM əlçatmaz olsa deterministik intent mühərriki cavab verir (agent heç
vaxt səssiz uğursuz olmur).

## Quraşdırma (bir dəfə)

```bash
# 1. Ollama qur:  https://ollama.com/download
# 2. Model çək (analiz üçün tövsiyə):
ollama pull qwen2.5:7b-instruct      # güclü, ~5GB
# və ya daha yüngül:
ollama pull qwen2.5:3b-instruct      # ~2GB
```

`.env`:

```
AI_MODEL_PROVIDER=local
LOCAL_LLM_ENDPOINT=http://127.0.0.1:11434
LOCAL_LLM_MODEL=qwen2.5:7b-instruct
LOCAL_LLM_API=ollama
```

Ollama bu maşında artıq quraşdırılıb və işləyir (`127.0.0.1:11434`); yalnız
model çəkmək lazımdır. Model çəkiləndən sonra agent sərbəst yazıları anlayıb
daxili məlumatı təhlil edir. Ollama işləmirsə, deterministik qat işləməyə davam
edir.

## Təhlükəsizlik xülasəsi

- Bütün LLM trafiki loopback ilə məhdudlaşdırılır — internetə çıxış yoxdur.
- Prompt-a raw sirr (parol/açar/token) verilmir.
- Lokal olduğu üçün müştəri adı/kodu kimi biznes məlumatı təhlil üçün model-ə
  verilə bilər; bu məlumat maşından kənara çıxmır.
