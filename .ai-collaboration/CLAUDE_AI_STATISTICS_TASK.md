# Claude task: AI and Statistics frontend

Implement the frontend only after Codex has added the backend contract.

1. Build a calm, compact Statistics workspace. Do not add a marketing hero.
2. Keep filters immediately visible and understandable to a middle-aged office
   user. Metric and period changes must be automatic.
3. For a single metric, show a ring breakdown and a matching labelled bar list.
4. For `all`, stack clearly titled metric sections vertically.
5. Use no nested cards, decorative gradients or oversized text.
6. Make desktop, tablet and mobile layouts free of clipping and nested scroll.
7. Move all AI inline styles and scripts to `css/ai-center.css` and
   `script/ai-center.js`.
8. In AI, separate everyday tools from admin-only technical controls. Render
   only sections present in the backend-provided section map.
9. Preserve all `data-*` hooks documented in the backend contract.
