# SuperOptic Claude Code qaydalari

Canli layihe yolu `D:\xampp\htdocs\superopticnet`-dir.

Her frontend tapsiriginda evvelce bu fayllari oxu:

- `.ai-collaboration/TASK.md`
- `.ai-collaboration/FILE_OWNERSHIP.md`
- `.ai-collaboration/BACKEND_CONTRACT.md`
- `.ai-collaboration/CLAUDE_FRONTEND_TASK.md`

Yalniz `TASK.md` statusu `READY` olduqda real deyisiklik et. Movcud istifadeci deyisikliklerini geri qaytarma. Isin sonunda deyisdirilen fayllari ve testleri `.ai-collaboration/CLAUDE_FRONTEND_RESULT.md` faylinda qeyd et.
